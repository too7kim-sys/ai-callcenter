임베디드 위젯 데모

이 페이지는 외부 사이트에 위젯이 설치된 상황을 시뮬레이션합니다. 오른쪽 아래 챗 버블 버튼이 보이면 정상이며, 클릭하면 콜센터 위젯이 열립니다.

외부 사이트 설치 방법

HTML 어디에든 다음 한 줄을 추가하세요:

<script src="/widget/loader.js" defer
        data-color="#1d4ed8"
        data-title="고객 지원"
        data-greeting="무엇을 도와드릴까요?"
        data-position="right"></script>

옵션

  • data-color — 브랜드 색상 (기본 #1d4ed8)
  • data-title — 위젯 헤더 제목
  • data-greeting — 시작 화면 인사말
  • data-position — right 또는 left (기본 right)

JavaScript API (외부 사이트에서 제어)

// 외부 사이트 코드에서 호출 가능
aiCallcenter.open();    // 위젯 열기
aiCallcenter.close();   // 닫기
aiCallcenter.toggle();  // 토글

// 위젯 이벤트 수신
window.aiCallcenter = window.aiCallcenter || {};
window.aiCallcenter.onMessage = function (e) {
  // e.type: "ready" | "started" | "message" | "agent_reply" | "close"
  console.log("위젯 이벤트", e);
};
ⓘ 위젯 iframe 안의 채팅은 콜센터 서버의 /api/conversations 등 기존 API 를 그대로 사용합니다. 외부 사이트에서 보면 같은 도메인이라 CORS 이슈 없음.
